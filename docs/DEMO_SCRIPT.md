# 3-minute demo script

**0:00–0:20 — Hook.** "One blurry leaf photo can cost a season. Watch this."
Open the app, hit **Try demo**, report appears with severity + confidence.

**0:20–1:00 — Upload.** Drag a real leaf photo. Show inline validation
(rename a `.txt` → error, no popups), file chips, provider pills.

**1:00–2:00 — Report.** Point out confidence ring, symptoms grid,
treatment + prevention, copy/share/print, 5-star feedback.

**2:00–2:40 — Depth.** Library tab (8 diseases), History restore/export,
Hindi/Marathi switch, dark mode.

**2:40–3:00 — Tech.** `/docs` Swagger, `pytest -q`, `npm run build`,
Docker. Close: "Demo offline, live with one API key."
